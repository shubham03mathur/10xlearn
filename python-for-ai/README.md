# Python for AI

## This module is a structured way to learn, or revisit, Python fundamentals with an AI-focused mindset.

### Target Audience

Devs coming from other programming languages, or anyone who wants to start building AI projects with Python.

### Why this module

When people start with AI, they often jump directly into frameworks, notebooks, or model APIs.
That works for getting started fast, but it can also make Python feel like something you are using without really understanding.

This module is meant to fix that.
The idea is to build a practical Python foundation first, so AI concepts, libraries, and workflows feel easier to understand and use.

### What you will learn

- core Python fundamentals that are useful in AI work
- how Python code is commonly written in notebooks and small AI projects
- the basic building blocks you will keep seeing in AI libraries and examples
- enough Python confidence to read, tweak, and build AI-related code on your own

### How to use it

This module is best used in a step-by-step way.
Go through the topics in order, practice the examples, and focus on understanding the patterns rather than just finishing the notebook.

If you already know Python, you can use this as a quick refresh with an AI use case in mind.

### Get the most out of it

Follow the guide step by step instead of jumping between topics.
The flow is designed to help the concepts build on each other, which makes the learning process smoother.

It is also a good idea to use a virtual environment while working through this module, so your setup stays clean and isolated.

If you use VS Code, install the `Jupyter Notebook extension` as well.
That will make it easier to run and follow the notebook-based parts of this module.

### Goal

The goal is not to make you a Python expert from day one.
The goal is to make Python feel natural enough that you can start learning and building AI projects with less friction.
